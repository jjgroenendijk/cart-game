## Scope

Retire the terrain Sobel `PostOutlinePass` from the per-view composer. Add
`UnrealBloomPass` in linear HDR (before the single ACES tonemap in
OutputPass) so bright highlights glow: sun-disc core + corona, water glints,
bright sand. Add a sun-aware sky halo inside `SkyPosterizePass` (a radial
glow + brighter hotspot folded into the synthetic sky gradient around the
projected sun screen-uv, sky-masked so terrain/walls occlude it for free)
driven per slot by `Renderer.applySunGlow` from `dayCycleState`. Soften the
`SunDisc` into a bright core + larger dimmer corona so bloom reads a glowing
core rather than a hard flat dot. Cel base colors stay readable via a high
bloom threshold. Inverted-hull outlines (layer 0, karts/props) are untouched.

## Code-verified (this pass)

- No terrain Sobel anywhere: `PostOutlinePass` + `postOutline.ts` + test
  deleted (commit 1); no remaining import. Inverted-hull outline
  (`InvertedHullMaterial`) intact for layer-0 solid geometry.
- Bloom in the chain: `Renderer.buildSlot` inserts `UnrealBloomPass`
  between `RenderPass` and `OutputPass` on the HalfFloat LINEAR
  readBuffer; the single ACES tonemap stays in `OutputPass` (commit 5).
- Bloom tier-gated: `quality.ts` `QualityKnobs.bloom` per tier — low
  `{0.35, 0.4, 0.85}`, med `{0.6, 0.5, 0.8}`, high `{0.8, 0.6, 0.75}`
  (low softer, not off); `quality.test.ts` asserts.
- Sun-aware halo: `skyPosterize.ts` sky branch adds a radial
  `exp(-d*d/r*r)` halo + a tighter hotspot around `uSunUv`, guarded by
  `uSunVisible > 0.5 && uSunGlowIntensity > 0.0`; `uAspect` keeps it
  round (commit 3). Neutral defaults (`uSunVisible 0`,
  `uSunGlowIntensity 0`) reproduce the pre-074 frame byte-identically
  (identity-path test).
- Per-slot drive: `Renderer.applySunGlow` (called per slot after camera
  matrix update) projects `dayCycleState.sunDirWorld` via `projectSunUv`,
  sets `sunVisible`/`aspect`, converts the LINEAR `sunColor` to sRGB
  (glow runs post-tonemap), and drives `sunGlowIntensity` via
  `glowIntensity(elev, sunInt, nightFactor, bloomStrength)` — so the
  halo tracks the sun, peaks dawn/dusk, fades by `1 - nightFactor`, and
  scales with the active bloom strength (commit 5).
- Behind-camera sun: `projectSunUv` returns `visible:false` (clip `w<=0`
  or NDC off-screen) -> `uSunVisible 0` -> glow skipped; unit-tested.
- SunDisc core + corona: `SunDisc.ts` renders both meshes additive,
  layer 0, `depthWrite:false`, fading by `1 - nightFactor`; corona at
  `radius * 2.5` x `0.25` opacity draws before the core so bloom has a
  soft gradient (commit 6).
- Full `npm run verify` gate green on the code commits
  (format -> typecheck -> lint -> lint:secrets -> test -> build ->
  lint:repo).
