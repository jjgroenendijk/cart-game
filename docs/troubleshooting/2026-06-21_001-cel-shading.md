## Commit 3 — outline

- Plan says "screen-space thickness (t / -mvPosition.z)". Verified the math:
  t/-z SHRINKS at distance (bug), not constant pixel width. Correct constant
  pixel-width = offset in CLIP space scaling with clip.w:
  `clip.xy += viewNormal.xy * uThickness * clip.w` -> post-divide NDC offset
  independent of depth. Implementing the CORRECT version (honors intent over
  literal buggy formula). Test asserts projected width constant across depths.
- No more flatGeometry: CelMaterial shades flat in-shader, geometry keeps
  smooth normals -> outline (smooth normal) silhouette is clean, resolves
  the faceted-silhouette mismatch the plan flagged. depthWrite=false +
  polygonOffset to kill z-fighting.
